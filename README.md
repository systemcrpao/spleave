# 📋 Leave Management System (LINE x Google Sheets)

ระบบบริหารจัดการการลาออนไลน์สำหรับบุคลากรภายในหน่วยงาน ผ่าน LINE LIFF โดยใช้ Google Sheets เป็นฐานข้อมูลกลาง และ Google Apps Script (GAS) เป็น REST API

## 🛠️ Architecture & Tech Stack

- **Frontend:** HTML/JS/React (Hosted on GitHub Pages)
- **Authentication:** LINE Front-end Framework (LIFF)
- **Backend/API:** Google Apps Script (GAS)
- **Database:** Google Sheets
- **Notifications:** LINE Notify

## 👥 Roles & Permissions (ระดับสิทธิ์การใช้งาน)

ระบบแบ่งผู้ใช้งานออกเป็น 3 ระดับ โดยแต่ละระดับจะมองเห็นเมนูที่แตกต่างกัน:

### 1. ผู้ใช้งานทั่วไป (User)

สิทธิ์สำหรับบุคลากรทั่วไปในการจัดการข้อมูลของตนเอง

- **แดชบอร์ดส่วนตัว:** ดูโควต้าวันลาคงเหลือประจำปีงบประมาณ (เช่น ลาป่วย ลากิจ ลาพักผ่อน)
- **แบบฟอร์มการลา:** ยื่นขอลางาน, แนบไฟล์หลักฐาน (เช่น ใบรับรองแพทย์)
- **ประวัติการลา:** ติดตามสถานะการอนุมัติใบลาของตนเอง

### 2. เจ้าหน้าที่ / ผู้ดูแลระบบ (Officer / Admin)

สิทธิ์สำหรับเจ้าหน้าที่ฝ่ายที่รับผิดชอบระบบ (เช่น ฝ่ายทรัพยากรบุคคล หรือ ฝ่ายอำนวยการ) เพื่อตรวจสอบความถูกต้องเบื้องต้น

- _รวมสิทธิ์ทั้งหมดของ "ผู้ใช้งานทั่วไป"_
- **ระบบอนุมัติผู้ใช้งานใหม่:** ตรวจสอบและอนุมัติการลงทะเบียน พร้อมตั้งค่าวันลาสะสมเริ่มต้น
- **ตรวจสอบใบลา (Pre-approve):** ตรวจสอบความถูกต้องของใบลาและเอกสารแนบ ก่อนส่งต่อให้ผู้บริหาร
- **รายงานภาพรวม:** ดูสถิติการลาของบุคลากรทั้งหมดในหน่วยงาน

### 3. ผู้บริหาร (Executive)

สิทธิ์สำหรับผู้มีอำนาจลงนามอนุมัติการลาขั้นสุดท้าย

- _รวมสิทธิ์ทั้งหมดของ "ผู้ใช้งานทั่วไป"_
- **กระดานผู้บริหาร (Executive Dashboard):** สรุปภาพรวมรายวันว่าวันนี้มีใครลาบ้าง
- **อนุมัติการลา (Pending Approvals):** อนุมัติหรือปฏิเสธคำร้องขอลางานที่ผ่านการตรวจสอบจากเจ้าหน้าที่แล้ว

## 🗄️ Database Schema (Google Sheets Structure)

เพื่อให้ระบบประมวลผลได้อย่างรวดเร็ว ข้อมูลจะถูกแยกออกเป็น Sheet ต่างๆ ดังนี้:

1. `Users`: เก็บข้อมูลโปรไฟล์ (`UID`, `Name`, `Position`, `Department`, `Role`, `Status`)
   - _ตัวอย่างข้อมูล:_ `U123...`, `Yanarit Hansomsook`, `นักวิชาการ...`, `ฝ่ายอำนวยการ`, `Officer`, `Active`
2. `LeaveQuotas`: เก็บโควต้าวันลาตามปีงบประมาณ (เช่น ปี 2569)
3. `LeaveRequests`: เก็บรายการขอลางาน รวมถึงผู้อนุมัติ
   - _ตัวอย่างผู้อนุมัติ:_ `Athitathorn Wanchaitanawong` (Executive Role)
4. `Holidays`: เก็บข้อมูลวันหยุดราชการประจำปี เพื่อนำไปคำนวณหักลบวันลาอัตโนมัติ

## 🔄 User Flow

1. **Login:** เข้าใช้งานผ่าน LINE > ตรวจสอบสิทธิ์ผ่าน GAS
2. **Register:** หากยังไม่มีข้อมูล จะแสดงฟอร์มลงทะเบียน > สถานะ `Pending`
3. **Approve User:** เจ้าหน้าที่ (Officer) กดยืนยันตัวตน > เริ่มใช้งานได้
4. **Request Leave:** ผู้ใช้ยื่นลา > แจ้งเตือน LINE Notify ไปยังกลุ่มเจ้าหน้าที่
5. **Workflow:** เจ้าหน้าที่ตรวจสอบ (Officer) -> ส่งเรื่องให้ผู้บริหาร (Executive) อนุมัติ -> แจ้งเตือนกลับไปยังผู้ใช้
